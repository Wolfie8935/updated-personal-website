# The Enchanted Edition — a reader for explorers

This file is for visitors who enjoy **wizarding-world-inspired** presentation and lore.  
It is **not** a walkthrough.

---

## What this is

The public site has a **special presentation mode**—think of it as stepping into a different wing of the same library. The facts (projects, papers, links) stay real; the **framing** turns theatrical: newspapers, maps, riddles, and a few challenges that treat the page like a place, not just a document.

## How to hunt (vague by design)

1. **Switch the light** — The interface does not stay in one “mood” forever. Look for how the atmosphere changes.  
2. **Read like a detective** — Ordinary copy sometimes hides invitations. **Patience and curiosity matter more than speed.**  
3. **Use more than the mouse** — Some doors listen for **other kinds of input**.  
4. **Follow the map** — Not everything important sits in the first scroll.  
5. **Respect the silences** — If something stops when you leave, that is intentional; come back when you are ready.
