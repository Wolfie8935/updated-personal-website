# Portfolio

Personal site for **Aman Goel** — projects, research, experience, and contact. Built as a fast, accessible React app with a polished default presentation.

## Tech stack

- React + TypeScript  
- Vite  
- Tailwind CSS + component primitives  

## Scripts

| Command         | Description              |
| ---------------- | ------------------------- |
| `npm run dev`    | Local dev server          |
| `npm run build`  | Production build          |
| `npm run serve`  | Preview production build  |
| `npm run typecheck` | TypeScript check       |

## Secrets & easter eggs

The deployed experience includes **a few deliberate hidden interactions** for visitors who like to explore. They are optional, not required for reading the content, and **are not documented here**—part of the fun is discovering them in the browser.

For a separate, themed introduction that still avoids spoilers, see [`readme_wizard.md`](./readme_wizard.md).
